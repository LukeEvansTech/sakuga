# Surface: Sakuga web UI (Today, Catalogue, Cel, Log)

Mode: operate. Phone first (the 08:00 digest opens Today), desk second. Single user.
Task: glance at the cels new since the digest, open one or two, browse everything for sale now and
then, check that sweeps are running.

## Direction contract

FORM: Circle Catalogue (catalog: pop-culture-shelf-doujin-event-catalog), seed:248c7aa7a6a7ca0a re-rolled to
4fc883960dec2ebf7768a75aabf5c6fa; chosen challenger, verdict wins.

THESIS: The catalogue as a convention circle catalogue: every cel is a numbered cell in a dense,
ruled whole-cell grid. Refuses the default marketplace card grid of rounded floating tiles.

OWN-WORLD: Newsprint inverted onto oxblood: ground #1f0a0c, rules #5a1c22, shell red #7d1520, ink
#efe3cf, biro red #f05a4f for marks only, code gold #e8b04a for cell codes and numerals. Archivo Narrow
for codes, numbers and headings; system sans (Hiragino for Japanese) for titles. Square cells ruled
at 1px, no radius, no shadows except the photo's light ground.

STORY: Open Today, see "3 new cels since this morning" and the circled cells; tap one, judge the art
at full size, see every site it is on and its price history; the Catalogue holds the rest, struck
through when gone.

FIRST VIEWPORT: Tabs Today / Catalogue / Log under the wordmark; the count line; the 3-across grid
starting above the fold with circled new cells.

SIGNATURE: Hand marks as state: a red biro loop around each new cel's photo, a single biro strike
through a cel no longer for sale. Nothing else is hand-drawn.

RISK: Density on a phone; photos must stay big enough to judge the art (2 across under 360px,
4-6 across on desktop), and the Cel page carries detail.
